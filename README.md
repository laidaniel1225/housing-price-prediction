# Housing Price Prediction

## Overview
This project analyzes housing datasets and builds predictive machine learning models for housing price estimation.

## Objectives
- Predict housing prices using regression models
- Perform feature engineering and data cleaning
- Evaluate model performance
- Analyze relationships between housing variables

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NumPy
- Matplotlib
- Jupyter Notebook

## Methods
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Linear Regression
- Ridge Regression
- Cross Validation
- Model Evaluation

## Results
The project compared multiple regression models and achieved the best performance using linear regression with optimized features and cross-validation.

## Skills Demonstrated
- Machine Learning
- Data Analysis
- Statistical Modeling
- Feature Engineering
- Data Visualization
